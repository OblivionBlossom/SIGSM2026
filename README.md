## Actualizaciones del proyecto

### Actualización (01/09/2026)

Se continúa con el desarrollo e integración de los módulos principales del sistema S.I.G.S.M. Se realizaron los siguientes avances:

* Implementación y conexión de la **base de datos MySQL/MariaDB** con los módulos del sistema.
* Creación de las **ventanas e interfaces** necesarias para el funcionamiento de la aplicación.
* Implementación de **formularios para ingresar, consultar y actualizar información**.
* Desarrollo del módulo de **Gestión Documental**, incluyendo la organización y consulta de documentos.
* Implementación del módulo de **Encuestas**, permitiendo gestionar preguntas y almacenar las respuestas de los usuarios.
* Incorporación de las funciones de **administración**, con acceso destinado a los funcionarios autorizados.
* Integración del **código QR**, permitiendo a los usuarios acceder desde dispositivos móviles a los documentos y encuestas correspondientes.
* Conexión entre las interfaces y la base de datos para mantener la información **actualizada y consistente**.
* Organización del proyecto mediante **Git y GitHub**, facilitando el trabajo colaborativo y el seguimiento de los cambios realizados.

## Pasos para la instalación

Sigue estos pasos para tener el proyecto en tu computadora:

1. Haz clic en el botón verde que dice **Code** aquí arriba en GitHub.
2. Selecciona **Download ZIP** y descárgalo.
3. Descomprime el archivo `.zip` en la carpeta que prefieras de tu computadora.
4. Asegúrate de tener instalado XAMPP 8.x en tu computadora.
5. Copia la carpeta descomprimida dentro de la carpeta **`htdocs`** de XAMPP.

## Pasos para el uso

Para ver la página web en funcionamiento:

1. Abre el panel de control de XAMPP e inicia los servicios **Apache** y **MySQL**.
2. Abre tu navegador web.
